# Berika Tours — berikatours.ge

კერძო ტურების საიტი 5 ენაზე (en, ru, ka, ar, he). აწყობილია **Astro + TypeScript**-ით.
ყოველ ცვლილებაზე GitHub თვითონ აწყობს და აქვეყნებს საიტს (`.github/workflows/deploy.yml`), დაახლოებით 2 წუთში.

## ადმინ პანელი: https://berikatours.ge/admin/

ვახო შედის ელ-ფოსტით და პაროლით. პანელის განყოფილებები:
- **ტურები:** დამატება, რედაქტირება 5 ენაზე, ფოტო, დამალვა, წაშლა.
- **პარამეტრები:** კონტაქტები, ფოტოები, შეფასებები.
- **გალერეა:** ფოტოების ატვირთვა და წაშლა.

მონაცემები ინახება **Supabase**-ში (ბაზა + ფოტოები). ყოველი შენახვის შემდეგ Supabase GitHub-ს ატყობინებს და საიტი თავიდან აეწყობა.
დაყენება: **ADMIN-SETUP.md**. ბაზის სტრუქტურა და წვდომის წესები: `supabase/setup.sql`.

სანამ `src/config/supabase.ts` ცარიელია, საიტი აეწყობა ლოკალური ფაილებიდან (`src/content/`).

## სად რა იცვლება (კოდში)

| რა | ფაილი |
|---|---|
| Supabase-ის მისამართი და საჯარო გასაღები | `src/config/supabase.ts` |
| ტურებისა და პარამეტრების შემოწმების წესები (საიტი + ადმინი) | `src/lib/schema.ts` |
| ადმინ პანელი | `src/admin/main.ts`, `src/pages/admin/index.astro` |
| ბაზა, წვდომის წესები, ავტომატური განახლება | `supabase/setup.sql` |
| ლოკალური მონაცემები (Supabase-ის გარეშე) | `src/content/tours/*.json`, `src/content/settings.json` |
| საიტის დანარჩენი ტექსტები 5 ენაზე | `src/i18n/ui.ts` |

## მისამართები

- `/`, `/ru/`, `/ka/`, `/ar/`, `/he/`: მთავარი გვერდები
- `/tours/<slug>/`, `/ru/tours/<slug>/` …: ცალკე გვერდი ყოველი ტურისთვის
- `/sitemap-index.xml`: Google Search Console-ისთვის

npm run build    # შემოწმება + აწყობა dist/-ში
